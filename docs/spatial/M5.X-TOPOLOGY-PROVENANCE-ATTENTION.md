# M5.x — Topology, Provenance and Attention

**Status:** M5.1–M5.10 implementation slice verified

This slice makes the Spatial grammar operational without moving authority into
the browser. All records are versioned Zod contracts and all services are
scope-bound to `(workspace_id, node_id)`; the Node Event Store remains the
production replay/persistence adapter.

## Contracts and events

New stable contracts are registered in `src/spatial/contracts/index.ts`:

- `spatial.canonical-reference.v1`
- `spatial.endpoint-details.v1`
- `spatial.discovery-result.v1`
- `spatial.semantic-relation.v1`
- `spatial.subagent-lifecycle.v1`
- `spatial.interaction-provenance.v1`
- `spatial.attention-item.v1`
- `spatial.attention-marker.v1`
- `spatial.attention-focus.v1`

The retained event gateway accepts corresponding canonical events under
`spatial.*.v1`; no browser-owned event bus is introduced.

## UI boundary

`SpatialTopologySurface` is behind `spatial_topology_enabled=false` by default.
It exposes Endpoint Arc candidates, read-only details, accessible attention
items, explicit focus/return actions, and a no-focus-theft status. The existing
Canvas remains the space layer; DOM remains the interface layer.
