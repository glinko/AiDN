# M1.5 Primary Agent material prototype

**Status:** Verified implementation slice  
**Scope:** Deterministic presentation fixture; live Agent state begins after M2/M3.  
**Depends on:** [M1.4 white atmospheric environment](./M1.4-WHITE-ATMOSPHERIC-ENVIRONMENT.md) and [ADR-004](./ADR-004-primary-agent-visual-state-language.md)

The center of Prototype A is a small glass sphere with an inner luminous core,
a restrained accent halo/orbit, and a low-cost particle field where the quality
profile permits it. The fixture deliberately uses standard R3F materials; a
custom shader is deferred until profiling supplies evidence for one.

## State language

`primary-agent.ts` exposes the deterministic `READY → THINKING → WORKING →
OFFLINE` sequence. Every state has more than one channel: geometry/halo/core,
motion mode, and a semantic status label. `OFFLINE` switches to a simple matte
placeholder and keeps the `System`/Classic control-plane entry visible in the
DOM panel. Low and mobile profiles, plus `prefers-reduced-motion`, replace
pulse motion with a static channel.

The DOM label is a real focusable button (`Primary Agent, Ready` and its state
variants), not text baked into the canvas. Clicking it selects the presentation
fixture and never changes Node state.

## Acceptance evidence

| Criterion | Evidence |
| --- | --- |
| At least two visual channels per state | `primaryAgentVisuals` maps state, accent, motion, channel, and LOD; `tests/unit/spatial-prototype.test.tsx` checks the mapping. |
| Color is not the only signal | Status text, geometry channel, and motion/placeholder mode accompany every accent. |
| OFFLINE preserves System | `[data-aidn-system-placeholder]` stays in the DOM panel; the OFFLINE detail explicitly names the System entry. |
| Reduced motion is static | `primaryAgentVisual(..., true)` and low/mobile profiles return `motion: 'static'`. |
| Material has an LOD fallback | Low/mobile profiles use the simple sphere/core material path and zero/minimal particles. |

The fixture sequence is replayable from the panel and is presentation-only.
