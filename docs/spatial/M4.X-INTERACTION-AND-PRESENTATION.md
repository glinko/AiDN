## Boundary

M4 turns the Node-scoped Spatial Workspace into an explicit operator entry
point without making the browser an authority. Text, voice, form, and spatial
inputs become the same versioned Intent envelope. The gateway validates
scope, revision, references, authorization, and idempotency before a durable
session projection accepts a turn.

The implementation is intentionally transport-neutral. `WorkspaceSessionGraph`,
`DurableConversationService`, `GeneratedObjectService`, and
`SessionArtifactService` provide an in-memory retained adapter that can be
replaced by Node persistence and the canonical Event Store without changing
the DOM contract.

## Data and event contracts

M4 contract versions are declared in `src/spatial/contracts/index.ts`:

- `spatial.intent-envelope.v1`;
- `spatial.attachment-manifest.v1`;
- `spatial.workspace-session.v1`;
- `spatial.context-node.v1`;
- `spatial.conversation-turn.v1`;
- `spatial.generated-object.v1`;
- `spatial.artifact.v1`;
- `spatial.presentation-intent.v1`;
- `spatial.presentation-result.v1`.

M4 event parsing is added to the existing `SpatialEventGateway` for accepted
intents, session/context updates, conversation turn updates, generated object
updates, artifacts, and presentation requests/results. Unknown or malformed
events remain diagnosed and cannot reach the renderer.

## Conversation Surface contract

`ConversationSurface` is a DOM overlay. It owns keyboard focus, transcript
scrolling, live announcements, and mobile composition. The canvas receives no
turn text, presentation HTML, callbacks, CSS, or shader input. A response is
shown as text, carries a source-turn reference, and can create a bounded
Generated Object or collapse into a Session Artifact.

The current demo response is a deterministic local adapter. Replacing it with
the Primary Agent inbox/response transport is a follow-up implementation seam;
the envelope, session, turn, provenance, retry, and binding checks remain the
same.
