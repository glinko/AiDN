# M2.3 — Live Event Gateway

M2.3 keeps retained Node events on the canonical typed path before they reach
query state or view models. The gateway validates the envelope, checks Node
scope and revision/sequence ordering, deduplicates event IDs, and emits state
updates separately from presentation notifications.

## Implemented boundary

- `events.ts` defines versioned Workspace, Entity, Relation and Node Status
  envelopes and safe unknown-event diagnostics.
- `SpatialEventGateway` provides idempotent ingest/replay, per-Node scope,
  stale revision rejection and a resume cursor.
- `createWebSocketSpatialEventAdapter()` and the reconnecting wrapper accept a
  compatible stream without coupling transport to R3F.
- `useSpatialWorkspaceData()` applies validated events to Query cache and
  derives a new view model; raw events never mutate a mesh.

## Acceptance

| Acceptance ID | Criterion | Validation | Status | Deferred reason, if any |
| --- | --- | --- | --- | --- |
| `M2.3-AC-001` | Raw events cannot update the renderer directly | gateway callbacks and hook cache adapter; no renderer import | verified | None |
| `M2.3-AC-002` | Duplicate event IDs are idempotent | `tests/unit/spatial-data.test.ts` gateway replay test | verified | None |
| `M2.3-AC-003` | Reconnect resumes retained events with bounded backoff | resume cursor, reconnect adapter and delay unit assertions | verified | None |
| `M2.3-AC-004` | Out-of-order or cross-Node events cannot roll state back | stale sequence/revision and payload scope checks | verified | None |
| `M2.3-AC-005` | Unknown events are diagnosed and ignored safely | unknown/malformed gateway test | verified | None |

The stream adapter is deliberately compatible with the existing Event Bus; it
does not create a browser-owned second event plane.
