# M0.5 Spatial dependencies and bundle baseline

**Status:** Verified implementation slice  
**Scope:** `web/operator-dashboard` only; the Classic UI remains the default
entry surface.

## Dependency boundary

The route boundary uses a React `lazy()` import for
`src/spatial/spatial-route.tsx`. The module is evaluated only after the
`spatial_ui_enabled` flag, `#spatial` hash, and WebGL2 capability checks pass.
Classic code can still import route helpers and the feature-flag reader, but it
does not import Three.js, R3F, Drei, or Motion.

The loaded Spatial module contains the first renderer seam and keeps the actual
Canvas probe opt-in until M1. This makes the M0.5 network contract observable
without turning the preview into the M1 renderer implementation.

## Direct dependency license check

The four M0.5 dependencies are direct production dependencies. Their installed
package metadata was checked by
`pnpm verify:licenses`; each currently declares MIT:

| Package | Locked version | License | Role |
| --- | ---: | --- | --- |
| `three` | `0.185.1` | MIT | WebGL renderer |
| `@react-three/fiber` | `9.7.0` | MIT | React renderer bridge |
| `@react-three/drei` | `10.7.8` | MIT | R3F controls and helpers |
| `motion` | `13.2.0` | MIT | route transition primitives |

The package manager and lockfile remain pinned to pnpm `11.16.0`. CI installs
with `pnpm install --frozen-lockfile` before running the license check, so a
lockfile or dependency drift fails before the dashboard build.

## Bundle report and budgets

Run the following from `web/operator-dashboard`:

```text
pnpm install --frozen-lockfile
pnpm build
pnpm bundle:report
```

The deterministic report is written to
`web/operator-dashboard/test-results/bundle-report.json`, outside `dist/`.
Therefore `tools/build-operator-dashboard.sh` still stages exactly the Vite
generated asset directory and keeps its atomic activation behavior unchanged.

The first M0.5 baseline is:

| Graph | Raw JS | gzip | Brotli | Budget (gzip / Brotli) |
| --- | ---: | ---: | ---: | ---: |
| Classic initial | 952,042 B | 249,149 B | 206,833 B | 300,000 B / 240,000 B |
| Spatial lazy delta | 1,018,831 B | 274,436 B | 228,013 B | 450,000 B / 360,000 B |
| Dashboard total | 1,970,873 B | 523,585 B | 434,846 B | 800,000 B / 650,000 B |

The report recomputes gzip and Brotli per JavaScript asset, records the entry
and lazy chunk names, and fails when a budget is exceeded or a Spatial chunk is
missing. Budgets can be overridden for an explicitly reviewed CI profile with
the `AIDN_*_BUDGET` environment variables defined in
`scripts/report-bundle.mjs`.

`pnpm bundle:repro` rebuilds and reports twice, then compares the deterministic
JSON output. The production CI job runs the license check, bundle report, and
repeat-build check. `pnpm test:bundle` serves the built output and proves that
Classic requests no Spatial chunk, while two Classic → Spatial transitions
reuse one lazy chunk request.
