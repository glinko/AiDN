# M8 — Spatial Memory, Aging and Clustering

**Status:** M8.1–M8.8 verified (2026-09-05)  
**Owner:** `web/operator-dashboard/src/spatial/memory/`  
**Contracts:** `spatial.memory-layout.v1`, `spatial.memory-projection.v1`,
`spatial.memory-cluster.v1`, `spatial.memory-focus.v1`,
`spatial.memory-search.v1`, `spatial.memory-virtualization.v1`

M8 adds a presentation projection for long-lived Workspace history. It does
not create a browser-owned store: every projection keeps a canonical reference,
revision and provenance, while Node remains the authority for semantic
objects, relations, authorization and durable persistence.

## Delivered slices

- **M8.1:** `SpatialMemoryEngine` computes semantic preferred regions around
  the Primary Agent HOME anchor, uses a deterministic seed, bounded local
  collision avoidance, adaptive viewport scale, manual positions and reset.
- **M8.2:** Recent Memory is sorted by UTC activity and bounded by a visible
  budget. Pins are explicit exceptions; overflow becomes virtualized without
  deleting a record.
- **M8.3:** UTC inactivity, reuse, relevance, pin and unresolved state drive
  `ACTIVE → RECENT → OLDER → CLUSTERED → PERIPHERAL → VIRTUALIZED`. Threshold
  hysteresis prevents jitter and the layout records a policy revision.
- **M8.4:** Session Cluster promotion supports structural parent, project,
  topic, Endpoint, Agent, subsystem, similarity and manual criteria. Membership
  includes evidence, criterion revision, provenance and explicit stale members.
- **M8.5:** Relation reveal is on demand and bounded. Direction, type,
  offscreen state and an accessible relation list are available without
  changing canonical topology.
- **M8.6:** Pull-to-Focus follows `REQUESTED → MATERIALIZING → FOCUSED →
  RETURNING/PINNED`; unavailable/tombstone references remain visible with a
  reason, and canonical world positions are preserved.
- **M8.7:** Viewport culling, LOD0–LOD3, materialization/release and telemetry
  keep full render work bounded. The unit scenario covers 20,000 records with
  a 30-object render budget.
- **M8.8:** Metadata search is deterministic and reference-only. Authorization
  filtering occurs before ranking; results expose relevance evidence and can
  feed Pull-to-Focus. A semantic adapter can be added without requiring a
  vector database for the MVP.

## UI and rollout

`SpatialMemorySurface` is a DOM surface gated by
`spatial_memory_enabled=false`. It provides keyboard-searchable memory,
region counts, recent objects, cluster evidence, relation reveal and focus
feedback. Reduced motion is passed into the focus lifecycle. When the flag is
off, canonical Workspace data and the Classic fallback are unchanged.

The event gateway accepts the six M8 event IDs but does not create a second
browser event plane. Durable Node memory persistence, policy authorization and
semantic search remain typed adapter seams.
