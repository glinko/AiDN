# M7 — Mediated Remote Resources and Endpoint Test Frame

**Status:** M7.1–M7.7 verified on 2026-09-05  
**Decision boundary:** [ADR-012 — Local Trust Boundary and Mediated Remote Resources](./ADR-012-local-trust-boundary-and-mediated-remote-resources.md)

M7 adds a bounded, local mediation seam for useful Endpoint work without
turning a remote resource into an Agent or authority. The browser receives a
canonical Endpoint reference and a typed adapter; it never receives an
arbitrary remote URL, credential, socket, callback, or remote component.

## Implemented surface

- `web/operator-dashboard/src/spatial/contracts/index.ts`
  - `spatial.endpoint-provenance.v1`
  - `spatial.remote-context-manifest.v1`
  - `spatial.remote-request.v1`
  - `spatial.remote-result.v1`
  - `spatial.endpoint-test-frame.v1`
  - `spatial.resource-accounting.v1`
- `web/operator-dashboard/src/spatial/remote/mediation.ts`
  - workspace/node-scoped canonical Endpoint registration;
  - authorization, capability, availability, revision and session gates;
  - allowlisted context manifest with secret redaction, attachment hashes and
    bounded payload size;
  - injected `RemoteTransportAdapter` only (no direct socket or URL path);
  - timeout/cancel, correlation, idempotency and bounded event log;
  - untrusted result validator for MIME, size, prompt injection, scripts,
    unsafe HTML and secret patterns;
  - provenance and Node-authoritative free/metered accounting records.
- `web/operator-dashboard/src/spatial/remote/EndpointTestFrame.tsx`
  - explicit Submit only;
  - what-will-be-sent summary;
  - response/provenance in the same local frame;
  - inert text rendering and keyboard/live-region semantics.
- `web/operator-dashboard/src/spatial/data/clients.ts` and `events.ts`
  - typed `remoteMediation` query/mutation seam and retained event IDs.
- `spatial_remote_mediation_enabled` defaults to `false`; enabling it exposes
  the frame from the existing Endpoint topology surface while local
  inspection/provenance remains available when rolled back.

## Production adapter boundary

The in-memory fixture adapter used by the unit/UI tests is deliberately not a
production transport. A Node implementation must provide the
`RemoteTransportAdapter`/`remoteMediation` client handler and own authorization,
policy, endpoint allowlisting, session leases, durable audit/replay, rate-card
settlement, and provider redirect/SSRF controls. The browser contract is
therefore useful now without claiming that a remote socket is available in the
presentation layer.
