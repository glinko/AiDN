# M1.6 Mock spatial entities and picking

**Status:** Verified implementation slice  
**Scope:** Synthetic visual grammar only; entities are not API projections.  
**Depends on:** [M1.5 Primary Agent material](./M1.5-PRIMARY-AGENT-MATERIAL.md) and [ADR-005](./ADR-005-spatial-entity-topology.md)

Prototype A renders a stable semantic fixture: 3 Subagent presences, 7
Endpoint energy objects, 6 Session Artifacts, 3 Attention Markers, and 2
semantic threads. `entities.ts` owns the IDs, labels, descriptions, positions,
priorities, relations, and LOD function. LOD changes geometry/opacity only; it
does not change identity.

WebGL mesh events provide the raycast path. The 2D fallback resolves the same
selection contract by nearest screen position. Both paths call the local
selection callback only; selection highlight and tooltip text have no protocol
effect. Endpoint particles use a bounded `InstancedMesh` field in the WebGL
scene, capped by the active quality profile.

The DOM panel contains a keyboard-accessible parallel entity list. Each item is
a native button with `aria-pressed`, class label, and a short description that
appears as a tooltip on hover/focus. No duplicate focusable canvas object is
created.

## Acceptance evidence

| Criterion | Evidence |
| --- | --- |
| Classes are visually distinct | Sphere, octahedron, box, and torus/triangle fallback geometries use violet, cyan, peach, and attention accents. |
| Hover/focus has no duplicate object | Canvas is `aria-hidden`/`tabIndex=-1`; only the DOM entity button is focusable. |
| Click only selects | `SpatialWorkspace.selectEntity` updates local selection and opens the readout; no API or mutation callback exists. |
| Mouse, touch, and keyboard select | Canvas pointer path and the native keyboard entity list share `selectNode`; `tests/e2e/spatial-prototype.spec.ts` exercises the list. |
| LOD preserves identity | `spatialEntityLod` is a pure distance/profile function and unit-tested against stable IDs. |

Entity counts are exposed as `data-aidn-entity-counts="3/7/6/3"` for deterministic
fixture verification.
