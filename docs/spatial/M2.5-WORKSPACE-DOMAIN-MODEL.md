# M2.5 — Node-owned Workspace Domain Model

M2.5 separates durable semantic Workspace state from device-local presentation
state. The semantic contract includes Node ownership, revisioned canonical
entities and relations, semantic anchors, cluster membership and timestamps;
the viewport contract carries camera, selection, opened frames and quality.

## Implemented boundary

- `contracts/index.ts` contains `spatial.workspace.v1` and
  `spatial.viewport.v1` with independently versioned revisions.
- `workspace/model.ts` validates ownership, clones state at the boundary,
  resets presentation without changing semantic data, and preserves the
  Workspace across Agent detach/replacement.
- `workspace/repository.ts` stores semantic and presentation data separately.

## Acceptance

| Acceptance ID | Criterion | Validation | Status | Deferred reason, if any |
| --- | --- | --- | --- | --- |
| `M2.5-AC-001` | Workspace ownership is Node-scoped, not Agent-scoped | ownership assertions and model tests | verified | None |
| `M2.5-AC-002` | Agent replacement/detach preserves Workspace entities | `workspaceSurvivesAgentChange()` unit test | verified | None |
| `M2.5-AC-003` | Semantic and presentation revisions remain independent | model reset/version unit test | verified | None |
| `M2.5-AC-004` | Cross-Node snapshots are rejected | Node mismatch model test | verified | None |
| `M2.5-AC-005` | Presentation reset cannot mutate canonical data | semantic snapshot remains unchanged in model/repository tests | verified | None |

The model is intentionally persistence-agnostic; the in-memory repository is a
deterministic acceptance seam for the later HTTP adapter.
