# M1.4 White atmospheric environment

**Status:** Verified implementation slice  
**Scope:** Spatial Prototype A only; no canonical data or protocol authority.  
**Depends on:** [M1.3 hybrid renderer shell](./M1.3-HYBRID-RENDERER-SHELL.md) and [ADR-014](./ADR-014-spatial-ui-technical-architecture.md)

M1.4 establishes the bounded studio environment used by both the WebGL scene
and its 2D capability fallback. The visual target is high-key and almost
white: a soft matte ground, a quiet horizon, and enough neutral contrast for
glass and distant semantic objects to remain legible.

## Implementation contract

- `src/spatial/prototype/environment.ts` defines `low`, `mobile`, `desktop`,
  and `high` profiles with bounded fog, DPR caps, material/shadow/reflection
  flags, and particle budgets.
- `SpatialEnvironment.tsx` uses a background color, `THREE.Fog` through the
  R3F `<fog>` primitive, a Hemisphere Light, bounded key/fill directionals, a
  matte plane, and the neutral Drei `studio` environment map for richer
  profiles.
- There is no visible grid, volumetric cloud mesh, depth-of-field, or other
  continuous post-processing in this prototype.
- `SpatialCanvas` mirrors the atmosphere and fog range in the fallback canvas;
  `frameloop="demand"` and a visibility-aware performance probe avoid an idle
  animation/sampling loop when a tab is hidden. Returning to the tab starts
  only the remaining bounded sample window.

The profile is a fidelity choice, not a semantic choice: changing it never
changes entity IDs, labels, selection, or authority boundaries.

## Acceptance evidence

| Criterion | Evidence |
| --- | --- |
| Distant objects lose contrast predictably | `spatialEntityLod` and distance opacity are deterministic; `tests/unit/spatial-prototype.test.tsx` covers far-object LOD. |
| Glass remains visible on an almost-white field | Primary Agent uses an opaque core, accent channel, and bounded halo over `#f8fbfe`; the fallback paints the same channels. |
| Mobile idle stays bounded | Mobile caps DPR at `1.25`, lowers shadows/reflections/particles, and uses demand rendering; `tests/e2e/spatial-prototype.spec.ts` checks the mobile profile. |
| Hidden tabs do not run continuous sampling | The performance probe pauses on `document.hidden`; `updateSpatialPerformanceFrame` and the M1.8 gate test this behavior. |

Run `pnpm verify:prototype`, `pnpm test:prototype`, and `pnpm test:a11y` from
`web/operator-dashboard` for the static, browser, and accessibility checks.
