# M2.4 — Spatial View Models

M2.4 turns canonical Node records into deterministic, renderer-safe
projections. The model carries provenance and source revision, explicit
freshness/familiarity/activity labels, and quality hints while excluding
credentials and arbitrary payloads.

## Implemented boundary

`web/operator-dashboard/src/spatial/data/view-models.ts` exposes specialized
Agent, Endpoint, Session/Artifact, Attention and Node Status view-model types.
The composition function deduplicates canonical references and reserves the
Primary Agent for its dedicated central presence.
