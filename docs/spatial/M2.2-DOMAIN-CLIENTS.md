# M2.2 — Spatial Domain Clients and Query Keys

M2.2 introduces the typed transport seam between the operator dashboard and
Node-owned Spatial data. Domain clients consume the M2.1 contracts and return
validated snapshots; renderer modules are not part of this dependency graph.

## Implemented boundary

- `web/operator-dashboard/src/spatial/data/transport.ts` provides scoped REST
  transport, auth headers, request/correlation IDs, idempotency metadata and
  typed 401/403/404/409/422/network errors.
- `clients.ts` exposes Node status, Agent, Endpoint, Session, Resource, Event,
  Hook, Workspace and Relation clients.
- `query-keys.ts` includes both `hypervisor_id` and `node_id` in every key and
  keeps invalidation targets narrow.
