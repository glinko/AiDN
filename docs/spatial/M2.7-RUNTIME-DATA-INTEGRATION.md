# M2.7 — Spatial Runtime Connected to Mock-real Data

M2.7 replaces Prototype A's synthetic renderer input with a typed Workspace
projection. The route mounts the scoped TanStack Query hook, replays a retained
fixture stream, and passes only view-model entities/relations to the canvas and
DOM list. Direct entity-component fetches are not introduced.

## Runtime states

`ready`, `partial`, `stale`, `offline`, `empty`, `loading` and `error` remain
explicit. The DOM status pill and data attributes expose Node and semantic
revision; the canvas has a loading/data-recovery placeholder. Renderer errors
continue through the existing DOM error boundary.
